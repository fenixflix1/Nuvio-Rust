Como funciona a sincronização

Escolha abaixo quais dados usar do Simkl neste perfil. A biblioteca salva títulos na lista para assistir. A fonte de progresso lê o histórico e envia a atividade do player integrado para retomar em outros dispositivos. Sincronizar agora atualiza listas, histórico, notas e progresso.
